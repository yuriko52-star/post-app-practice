#### API-03: 投稿1件を書き換える  

- **メソッドとエンドポイント**: PUT /api/posts/{id}  
- **認証**: 必要  
- **送るもの**: URLに投稿の番号。本文で、タイトル（必須・255文字以内）と、本文（必須）と、カテゴリの番号（必須・登録済みのカテゴリのもの）  
- **返すもの（うまくいったとき）**: 200。書き換えた後の投稿1件（投稿の番号・タイトル・本文・カテゴリの番号・投稿者の番号・登録日時・更新日時）  
- **返すもの（うまくいかなかったとき）**: 401（ログインしていない時）/　403（自分の投稿でない時）/404（その投稿が見つからない時）/ 422（送ったものに不備があるとき）
